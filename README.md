# 🌸 CachyOS Dotfiles

My personal dotfiles for a minimal CachyOS + Hyprland setup.

## Setup

- **OS:** CachyOS
- **Window Manager:** Hyprland
- **Terminal:** Kitty
- **Shell:** Bash + Starship
- **Bar:** Waybar
- **Launcher:** Rofi
- **Notifications:** Mako
- **Wallpaper:** Hyprpaper
- **Idle / Lock:** Hypridle + Hyprlock
- **File Manager:** Thunar

## Included configurations

- Hyprland
- Waybar
- Rofi
- Kitty
- Mako
- Fastfetch
- Starship
- Bash

## Extras

The setup also includes custom scripts and keybindings for:

- Screenshots
- Clipboard history
- Volume controls
- Power menu
- Spotify controls
- CPU / GPU monitoring
